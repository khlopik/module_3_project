# Programmable Music Box

Програмований музичний автомат на ESP32-S3: вибираєте ноту енкодером, задаєте її тривалість,
записуєте ноти в мелодію і відтворюєте результат на буззері.

Пристрій задуманий як невеликий синтезатор з клавіатурою: обертання енкодера — це вибір
ноти, натискання його кнопки — запис ноти в мелодію, а окрема кнопка відтворює те, що ви
насклали.

---

## Можливості

- **9 позицій ноти** — до-мажорний октавний ряд C4…C5 плюс пауза (rest).
- **3 тривалості** — ціла (800 мс), чверть (400 мс), восьма (200 мс).
- **До 99 нот** у мелодії — стільки ж, скільки вміщає двозначний дисплей.
- **Живий перегляд ноти**: щойно вибрана нота одразу звучить на буззері.
- **Відтворення мелодії** з паузою 50 мс між нотами.
- **Індикація тривалості** чотирма світлодіодами (4 / 2 / 1).
- **Лічильник на дисплеї**: кількість записаних нот, а під час відтворення — скільки залишилося.
- **Сервопривід** показує вибрану ноту на шкалі.

## Обладнання

| Периферія | Призначення |
|---|---|
| ESP32-S3 N16R8 (плата розробника, Type-C) | Основний контролер |
| Ротаційний енкодер з кнопкою | Вибір ноти + запис ноти у мелодію |
| Кнопка «тривалість» | Перемикання тривалості ноти |
| Кнопка «play / reset» | Відтворення мелодії / очищення (довге натискання) |
| Буззер | Відтворення тонів |
| Сервопривод | Індикатор вибраної ноти |
| 4 світлодіоди | Індикатор тривалості |
| 2-значний 7-сегментний дисплей | Числовий лічильник |

Усі призначення пінів зібрані в одному місці — `include/config.hpp` (простір імен `pinConfig`).
Там само налаштовуються таймінги, частоти тонів і тривалості.

## Керування

| Дія | Результат |
|---|---|
| Обертання енкодера | Перехід до наступної ноти. Серво повертається у відповідну позицію, нота одразу звучить для перегляду й звучить стільки часу, скільки триває обрана тривалість. |
| Натискання кнопки енкодера | Записує поточну ноту з поточною тривалістю в мелодію. Лічильник на дисплеї збільшується на 1. |
| Натискання кнопки «тривалість» | Перемикання тривалості за циклом: ціла → чверть → восьма → ціла. Кількість засвічених світлодіодів показує обрану тривалість. |
| Коротке натискання «play / reset» | Відтворює записану мелодію. Під час відтворення повторне натискання зупиняє її. |
| Довге натискання «play / reset» | Очищає мелодію, скидає енкодер і тривалість. |

Енкодер дає 9 перехопів, тому перелік нот циклічний: після паузи знову повертаєтесь до C4.
Під час запису енкодер скидається, тож кожна наступна нота починається від C4.

## Як це влаштовано

Логіка розділена на незалежні модулі, кожен у своєму просторі імен:

- **`buttons`** — обробка трьох кнопок через компонент `espressif/button`. Натискання
  виставляють «запити», які основний цикл забирає через `consume*Request()`.
- **`encoder`** — підрахунок імпульсів енкодера через апаратний PCNT у квадратурному
  режимі X4; глобальний фільтр від збоїв і поділ на 4 імпульси на «щелчок».
- **`servo`** — керування кутом сервоприводу через LEDC (50 Гц, 500–2500 мкс).
- **`buzzer`** — генерація тону через LEDC зі змінною частотою.
- **`leds`** — показ тривалості.
- **`digits`** — керування двозначним 7-сегментним дисплеєм; сегменти мультиплексуються
  таймером GPTimer з інтервалом 10 мс.
- **`melody`** — клас, що зберігає ноти (частота + тривалість) і відтворює їх.
- **`config.hpp`** — усі константи проєкту: піни, таймінги, ноти, тривалості.

Основний цикл — суперцикл із затримкою 10 мс, у якому реалізована машина станів:
`SelectNote` → `PreviewPlayNote` → `SaveNoteToMelody` → `PlayMelody` → `Idle`.
Переходи між станами відбуваються за подіями від кнопок і енкодера.

## Збірка та прошивка

Потрібні PlatformIO та встановлений toolchain `espressif32`.

```bash
# збірка
pio run

# прошивка
pio run --target upload

# монітор послідовного порту (115200)
pio device monitor
```

Зібраний прошивний образ: `.pio/build/4d_systems_esp32s3_gen4_r8n16/firmware.bin`.

Після зміни конфігурації ESP-IDF (`sdkconfig.*`) проєкт перезбирається з нуля — PlatformIO
виконує повний `CMake`-конфіг.

## Відомі питання

**Попередження про розмір flash при збірці.**
`sdkconfig` містить `CONFIG_ESPTOOLPY_FLASHSIZE="2MB"`, тоді як на платі 16 МБ flash,
 тому PlatformIO пише `Flash memory size mismatch detected. Expected 16MB, found 2MB!`.
На роботу firmware це не впливає (прошивка ~210 КБ), але попередження варто прибрати,
 виставивши в `sdkconfig` розмір 16 МБ.

**Налаштування плати в `platformio.ini` вказує на інший борд.**
Зараз зазначено `4d_systems_esp32s3_gen4_r8n16` (4D Systems GEN4-ESP32), тоді як
фактично використовується плата розробника ESP32-S3 N16R8 Type-C. Обидві побудовані на
одному модулі ESP32-S3-R8N16, тому код працює на обох, але `board` у `platformio.ini`
варто змінити на відповідний профілю вашої плати.

**Керування і монітор.**
`pio device monitor` працює на 115200 бод. Порт визначається автоматично; якщо
`upload` не знаходить плату, вкажіть порт явно: `pio run -t upload --upload-port /dev/ttyACM0`.
